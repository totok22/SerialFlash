# VS Code 插件架构设计与历史规划归档

本文件归档了 STM32 Serial Flasher 扩展的核心架构设计决策与历史演进记录。当前系统行为与实现细节以源代码为准。

---

## 1. 架构分层设计

扩展采用分层解耦架构，保证协议、串口传输与 VS Code 界面交互各自独立：

```text
┌────────────────────────────────────────────────────────┐
│                   VS Code UI 交互层                    │
│   Webview Panel / Activity Bar Sidebar / Commands     │
│   Quick Pick / Status Bar / Output Channel / Tasks     │
└───────────────────────────┬────────────────────────────┘
                            │
┌───────────────────────────▼────────────────────────────┐
│                    插件业务逻辑层                       │
│   src/vscode/ (Controller, Settings, TaskProvider)     │
└───────────────────────────┬────────────────────────────┘
                            │
┌───────────────────────────▼────────────────────────────┐
│                      核心流程层                        │
│   src/core/flash-session.js   (ISP 烧录主流程)          │
│   src/core/reset-timing.js    (DTR/RTS 硬件时序)       │
│   src/core/firmware-discovery.js (工作区固件检索评分)   │
└─────────────┬────────────────────────────┬─────────────┘
              │                            │
┌─────────────▼──────────┐      ┌──────────▼─────────────┐
│      协议与解析层       │      │       硬件传输层        │
│   src/stm32.js (AN3155)│      │src/node-serial-transport│
│   src/firmware.js (HEX)│      │(Node serialport 极性反转)│
└────────────────────────┘      └────────────────────────┘
```

### 核心设计原则
1. **协议与传输解耦**：`src/stm32.js` 仅负责 AN3155 帧封包、校验与命令构造，不直接依赖硬件句柄；通过通用的 Transport 接口与底层串口交互，便于测试 mock。
2. **硬件电平约定与反转隔离**：项目内部统一将 `true` 定义为低电平（有效），`false` 定义为高电平；仅在 `src/node-serial-transport.js` 适配层与 Node.js `serialport` 原生语义进行单点转换。
3. **桌面扩展宿主定位**：烧录核心需要访问物理硬件串口，明确运行在 VS Code Desktop 的本地 Extension Host 中；在 Remote 开发模式下明确提示串口属于运行宿主所在机器。
4. **非侵入式固件发现**：基于工作区 glob 检索，排除编译器探测生成物（如 `CMakeFiles/`），并在用户已显式配置固件时严格保持配置优先。

## 2. 演进里程碑记录

- **MVP 阶段**：搭建命令面板、Quick Pick 串口与固件选择、基础 DTR/RTS 复位时序及 Output Channel 实时日志。
- **界面与体验增强**：引入 Webview 控制面板与 Activity Bar 侧边栏，提供中英文自适应界面、百分比烧录进度展示与最近历史记录管理。
- **工程化与自动化**：支持 Profile 命名配置多板卡切换、VS Code Tasks 编译烧录链式集成、断点/异常安全资源释放与宿主环境诊断工具。
